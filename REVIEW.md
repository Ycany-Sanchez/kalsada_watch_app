# KalsadaWatch App Review by Casidey Quibuyen

Reviewed by: Ycany Ashra T. Sanchez
Date: October 2, 2026
Scope: Frontend-only by design, no API implementation yet.

## Frontend — 8/10

The frontend looks clean and modern, with a clear home page, nice colors, icons, and easy buttons for Report, Map, and Feedback. The feedback section is well made, showing ratings, comments, and loading and empty states. As designed, the form is preview-only and the map and API are placeholders, so they are ready for backend work later. Only crticisms is map is still a static placeholder, form cannot save yet, and unused Bootstrap CSS and default NavMenu are still in the project.

## File Structure — 8/10

The files follow the normal Blazor layout with Pages, Layout, Feedback, and wwwroot, which makes it easy to find things. The feedback files are well grouped, with the model, data source, and mock data kept together. Since no API is planned yet, the flat Pages folder is fine for now, though removing sample pages like Counter and Weather would make it cleaner. My criticisms are sample pages Counter and Weather are still there, Pages are all in one folder with no feature grouping, and there are no tests yet.
