# KalsadaWatch App by Casidey Quibuyen
Reviewed by: Ycany Ashra T. Sanchez
Date: October 2, 2026

## Project Structure Rating — 8/10

The files follow the normal Blazor layout with Pages, Layout, and wwwroot so it is easy to find things. Naming is clear and feedback files are grouped well with the model and mock data kept together. It still needs cleanup since sample pages like Counter and Weather are still there, and the project is still not complete.

## Front-End Rating — 8/10

The layout looks clean and simple with clear buttons for Report, Map, and Feedback. Navigation is easy to use and the colors and text are consistent and readable. It is still incomplete since the map is only a placeholder and the form cannot save yet without the backend.
